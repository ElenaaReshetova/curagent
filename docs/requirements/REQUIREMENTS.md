# Требования v1

**Версия:** 1.0  
**Дата:** 2025-03-07

## Цель

Разработать ИИ-агента, который работает автономно и выполняет назначенные на него задачи.

## Архитектура решения

1. Задача назначается через таск трекер, Slack или чат.
2. Назначенные задачи попадают в очередь Kafka.
3. На бэке в отдельных контейнерах развернуты агенты, реализованные на базе OpenAI Agent SDK.
4. Дополнительный сервис (Task Manager) по крону опрашивает контейнеры на наличие свободного агента (анализ healthcheck) и, если находит свободного агента, вычитывает задачу из очереди Kafka и назначает на агента. Цикл повторяется бесконечно.
5. Агент выполняет задачи в соответствии с описанием:
   - 5.1. При выполнении агент проверяет, какие Skills полезны для задачи.
   - 5.2. В соответствии с Skills вызывает подключенные MCP tools.
   - 5.3. По завершении работы агент отправляет с помощью MCP tool сообщение в таск трекер или чат, откуда пришла задача, и ждет следующую задачу (на ручку проверки для Task Manager по запросу передает статус «свободен»).

## Сервисы

1. **Агент** — с поддержкой Skills (SKILL.md), MCP tools и возможностью подключаться к LM Studio, завернутый в контейнер.
2. **Task Manager** — подключается к Kafka, вычитывает задачи, проверяет наличие свободных контейнеров с агентами и назначает на них задачу.

## Язык разработки

Python с venv (все зависимости исключительно в venv).

## Архитектура кода

1. Должна соответствовать лучшим практикам (чистая архитектура).
2. Позволять отдельно упаковывать агента в контейнер (возможно несколько модулей или папок в проекте).

## Источники задач (MVP)

- Веб-чат для создания и получения задач.

## LLM-провайдер (MVP)

- LM Studio (локальные модели через OpenAI-совместимый API).
