# General Task Execution

Respond in the same language as the user's message.

When the task does not match a more specific skill:

1. Break the task into clear steps if it is complex.
2. Execute each step and verify the result.
3. If you need to search or look up information, use available tools.
4. Always call send_to_chat with the final result when done.
