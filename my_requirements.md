**Цель :** Мы хотим разработать ИИ-агента, который работает автономно и выполняет назначенные на него задачи. 
**Архитектура решения :** 
1. Задача назначается через таск трекер, слак или чат. 
2. Назначенные задачи попадают в очередь Kafka. 
3. На бэке в отдельных контейнерах развернуты агенты, реализованные на базе open ai agent sdk. 
4. Дополнительный сервис (таск менеджер) по крону опрашивает контейнеры на наличие свободного агента (анализ healthcheck) и, если находит свободного агента, вычитывает задачу и очереди KAfka и назначает на агента. И так в бесконечном цикле. 
5. Агент выполняет задачи в соответсвии с описанием. 
5.1. При выполнении агент смотрит, если Skills полезные для выполнения задачи.
5.2. В соответствии с выполненными Skills вызывает подключенные MCP tools
5.3. По завершению работы, агент отправляет с помощью MCP tool сообщение в таск трекер или чат, откуда пришла задача, и ждет следующую задачу (на ручку проверки для таск менеджера по запросу передает статус, что свободен).

**Сервисы :** 
1. Агент с поддержкой Anthropic Skills, MCP tools и возможностью подключаться к LM Studio, завернутый в контейнер;
2. Task manager, который подключает к kafka, вычитывает задачи, проверяет наличие свободных контейнеров с агентами и назначает на них задачу.

**Язык разработки :** Python с venv (все зависимости исключительно в venv)
**Архитектура :** 
1. Должна соответствовать лучшим практикам (чистая архитектура), 
2. позволять отдельно упаковывать агента в контейнер (возможно несколько модулей или папок в проекте).
